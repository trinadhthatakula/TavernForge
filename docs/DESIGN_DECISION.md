# Approved UI direction

Baseline: [project kickoff charter](../TavernForge_Project_Kickoff.html), section 08. Reference: [design comparison](design-comparison.html) and [Agent 3's proposals](design/proposals.md).

The user explicitly selected **“Hybrid: C’s library, A’s native controls, B’s expanded inspector (recommended)”** in the project conversation on 31 October 2026. This records approval; the initial recommendation alone was not approval.

- **Home and collections:** C's character-library hierarchy, warm identity, and equal access to character drafts and standalone lorebooks. Artwork-free projects remain first-class.
- **Forms and navigation:** A's native Material controls, comfortable targets, clear Basic/Advanced modes, compact navigation, and familiar consent/validation flows.
- **Expanded windows:** B's optional project/editor/validation inspector when space permits; keep the compact workflow focused and preserve state during resizing.
- **Shared behavior:** import/combine, manual creation, and Gemini all use the same canonical model and validation/export pipeline. Text/image/follow-up permissions stay independent. Generated drafts require explicit acceptance.

The HTML pages are design references, not implemented application features or proof of Android accessibility. Exact component choices and Android adaptive behavior must be verified during implementation. This decision does not change the requested dependency baseline, format contract, or release acceptance criteria.
