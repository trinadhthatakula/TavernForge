## Implemented

- `:core:model`: owned source bytes/SHA-256, resource budgets, diagnostics, projections, minimal project identity.
- `:format`: strict bounded UTF-8/JSON parsing, duplicate-name detection, unknown/null/number preservation, atomic revision-aware JSON Pointer patches, version-dispatched schema checks and strict same-format JSON export for the six supported JSON kinds. Untouched valid exports retain exact source bytes. Unknown/future versions remain inspectable with strict exports blocked. See the [support matrix](build/JSON_FORMAT_SUPPORT.md).
- `:data`: Room 3 project metadata, app-private content-addressed original/current JSON, integrity checks, interruption recovery, revision-checked editing and save/reopen/rename/duplicate/delete. The v1→v2 migration preserves existing sources. Schema-invalid edits can be saved as drafts; malformed JSON cannot.
- `:app`: real system-picker JSON intake, bounded streaming, background parsing, validation diagnostics, compact/expanded inspection, and the local library with search/sort and explicit save. App binding uses the Koin compiler plugin. Saved projects persist; active saved-project edits have bounded private recovery with explicit review after process death. Unsaved initial file inspection still requires selecting the file again. Saved JSON field/value editing and strict export are available through native controls and the system picker. Pending field input requires explicit Apply or Discard; source versions stay fixed.
- Root Gradle wrapper, pinned version catalog and dependency locks; [CI workflow](../.github/workflows/android.yml) with tests, fixture audit, APK build, and seven-day artifacts.

## Milestones and remaining work

M0–M7 have a working internal implementation for the documented supported profile: six JSON kinds, static PNG/JPEG workflows, offline persistence/manual authoring, optional consent-controlled Gemini and recovery/backup. GPL-3.0-or-later, notices, public GitHub CI/security features and contributor documentation are present. This does not certify every external-provider/device combination.

Before a broad community release: perform a user-entered-key Google smoke test with reviewed requests, receiver-application imports beyond the pinned PNG reader, broader TalkBack/hardware checks, signing/distribution setup and final identity/minimum-SDK review. APNG/CHARX/embedded-media and cross-version conversion are explicit unsupported scope, not silent transformations. Pending provider calls must never be fabricated or run with a repository key.
