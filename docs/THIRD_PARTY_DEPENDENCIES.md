## Scope and evidence

The graph contains **184 coordinates**: **182 Apache-2.0, one BSD-3-Clause and one MIT**. Inventory SHA-256: `aa6816f3bf5c318666d6b13f9ac865b66cbd2cae72a2b8a71d0b77714250a7d6` (sorted exact coordinate lines, UTF-8, one trailing newline).

These are graph nodes, not 184 independent binary libraries. Version platforms supply dependency constraints; variant selectors redirect to platform artifacts. The three platforms are identified by published POM `pom` packaging with dependency management; selectors are identified by Gradle module runtime variants whose `available-at` coordinates are also in the locked graph. “Runtime component” identifies the remaining resolved nodes and does not assert that all their code survives R8. Project modules, build tools, Gradle plugins, compiler dependencies and test-only fixtures are outside this runtime inventory. Pinned SillyTavern fixture material retains its separate [fixture provenance and license](../format/fixtures/README.md); it is not an Android runtime dependency.

License identifiers come from exact published Maven POMs in the local Gradle cache, including parent inheritance. The table links to canonical published POM locations constructed from the resolved coordinates; the graph inventory used cached POMs. The protobuf follow-up below separately retrieved authoritative source and its exact POMs. Source links are the POM's SCM URL, inherited SCM URL, or project URL. They identify upstream projects, not verified source commits corresponding to the binaries. Organizations/developers in the asset are quoted as published metadata, not inferred copyright holders. A lockfile change requires regeneration and review.
