# Pinned PNG reader interoperability harness

Baseline: [project kickoff charter](../../../../TavernForge_Project_Kickoff.html) and [PNG contract](../../../../docs/planning/PNG_COMBINE.md). This development-only harness executes the exact vendored SillyTavern reader and its exact encoder import, pinned to `06bde939fb1e9c4c8d8641d810f0a916b5bce127`. It does not start the SillyTavern server or prove its UI behavior.

`provenance.json` records source SHA-256 values, the full upstream lock hash, exact four npm package versions/tarball URLs/SRI integrities, and generated fixture hashes. `package-lock.json` contains only the corresponding pinned reference dependencies: `png-chunks-extract@1.0.0`, `png-chunk-text@1.0.0`, `crc-32@0.3.0` and `crc@4.3.2`. Product Android dependencies are unchanged. npm lifecycle scripts are disabled. Upstream AGPL and source-header MIT attribution remain in `../../upstream/sillytavern`; package licenses remain in installed dependencies.

From repository root, the supervisor runs:

```sh
npm ci --ignore-scripts --no-audit --no-fund --prefix format/fixtures/reference/png
./gradlew :format:test --tests '*PngReferenceArtifactsTest' --offline --no-daemon --console plain
node format/fixtures/reference/png/check.mjs format/build/png-reference
python3 format/fixtures/verify_manifest.py
```

The JUnit class reads actual pinned-writer PNG fixtures and emits six actual TavernForge outputs (V1/V2/V3, exact no-op and edited). The Node harness verifies exact decoded JSON through the unmodified upstream reader, correct metadata keywords, and an independent bitwise CRC/chunk oracle checks every output and unchanged non-card chunk. Outputs stay under ignored `format/build/png-reference`.

The committed three PNG inputs were generated by `node format/fixtures/reference/png/check.mjs --generate-upstream`. This explicit maintenance mode writes only their known fixture paths. The original one-pixel RGBA artwork is authored in the runner under GPL-3.0-or-later. `st-writer-v2.png` and `st-writer-v3.png` call the actual upstream `write()` with this artwork and the attributed JSON fixtures. They are **upstream-writer outputs**, not claimed exports from a running SillyTavern UI. Regeneration requires updating the main fixture manifest, provenance hashes and byte-identical JVM resource copies.

The pinned writer relabels V2 into a preferred V3 payload without required V3 fields. The fixture deliberately preserves this behavior: TavernForge imports it as an invalid V3 draft and allows explicit recovery of its valid `chara` candidate. It does not copy that relabeling. The V3 writer fixture retains both chunks until the exact replacement plan is reviewed.

Limitations: Node's reader is permissive, so its success is not a strict encoding/schema test. Kotlin checks and ImageIO pixel/chunk-preservation tests are separate. APNG, embedded-asset resolution and receiving application UI still need their separate acceptance gates.
