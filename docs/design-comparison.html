Agent 3 recommendation · proposed hybrid

C’s library.
A’s native controls.
B’s expanded inspector.

A distinct home for characters, familiar Android editing and consent, and additional workspace tools when the window has room. Start with compact workflows. This recommendation is available as a hybrid choice; it does not select a direction for you.

Every direction keeps the three entry points.

01 / Combine existing files

Select character JSON, lorebook, or PNG independently. Inspect sources, associate assets, review validation, and export eligible outputs. Missing artwork does not prevent JSON export.

02 / Generate with Gemini

Configure your key and independent permissions. Preview model, purpose, data, and limits. Review a validated draft and explicitly accept it before saving. Images stay off by default.

03 / Build manually

Choose a template, edit Basic or Advanced fields, author lore, and validate. No key or network is required. Format requirements remain distinct from writing suggestions.
