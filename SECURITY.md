# Security policy

Baseline: [TavernForge kickoff charter](TavernForge_Project_Kickoff.html). TavernForge is under active development; current builds are for testing. Security fixes are developed on `main`; no stable release support window is promised yet.

Please use [GitHub private vulnerability reporting](https://github.com/trinadhthatakula/TavernForge/security/advisories/new) to report a suspected vulnerability. Include the affected commit/build, reproduction steps, and the expected and observed behavior. Use synthetic inputs where possible. Do not include API keys, access tokens, private character documents, or other personal data in a public issue or pull request.

The maintainer will review private reports and coordinate fixes and disclosure. No response deadline or bounty program is promised.

Repository checks include Dependabot, secret scanning and push protection, CodeQL, dependency review, and resolved dependency submission. Passing automated checks does not replace review or Android device testing. Third-party references retain their own security and licensing context; see [notices](NOTICE.md).
